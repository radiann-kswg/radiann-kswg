## About

- 数字をキャラクターにした「ナンバーテールズ」、タロット78枚が題材の「運命線探偵78」、干支が題材の「獣爾騎兵」などの一次創作を制作しています。
- 公式サイトや設定データベースから、画像処理ツール、Unity 作品、自作 OS・自作 CPU まで、企画から公開までを個人で進めています。
- 開発には VS Code と AI エージェント（Claude / GitHub Copilot / Codex）を使います。`AGENTS.md` を正本にして各エージェントの指示ファイルを派生させる構成や、MCP で Blender・Unity を AI から操作する制作を実践しています。
